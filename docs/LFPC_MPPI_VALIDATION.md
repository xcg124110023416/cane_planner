# LFPC 连续转向 MPPI：实现与验证

2026-10-27，分支 `mpc-lfpc-prototype`，替换基线 `80f8ab2` 的 beam 控制器。
本次保留 A*、当前帧 FIRI、LFPC 模型、时间同步行人 SAT 及管理器执行前复查。

## 算法和参数

MPPI 优化未来每一步的连续相对转角，固定步长、步宽。当前 launch 默认：

| 参数 | 值 |
|---|---:|
| 预测步数 | 10 |
| 每轮序列数 / 迭代轮数 | 256 / 2 |
| 转角范围 | ±π/6 rad |
| 高斯扰动标准差 | 0.35 rad |
| 权重温度 | 0.4 |
| 随机种子 | 0，初始化播种一次 |
| 固定步长 / 步宽参数 | 0.40 / 0.0 m |

默认扰动从原共享参数的 0.15 rad 调至 0.35 rad：前者在冷启动转弯路线中难以找到
完整可行序列，后者在相同预算下通过两条转弯路线。planner 4 仍使用原来的
200 样本、1 轮及 0.15 rad 配置。

每轮保留提议与本周期最佳已验证序列，其余施加成对正负高斯扰动。不可行序列为
无穷代价、零权重；有限代价先减最小值，再指数归一化加权。加权序列必须完整重演
检查，不能因样本可行就假定均值可行。下一轮围绕更新后的提议继续采样。

至少一个加权结果可行时，执行初始可行提议与可行加权结果中的最低代价序列；
全部加权更新失败时才使用本周期最佳已验证候选。没有可行候选则 STOP。
执行前还独立重演选中序列，并保留管理器的观测时效和执行时间原点复查。
热启动为上次选中序列移位补零，仍须在当前状态与观测上重新验证。

代价仍由局部目标距离、转角幅度和相邻转角变化组成。局部目标到达不能跳过
后续步的安全检查与代价；只有安全进入实际最终目标范围才允许提前终止。
该有限采样实现提供加权优化过程，**不保证严格局部最优、全局最优或搜索完备性**。

## 自动验证

使用自有独立 ROS master，未修改用户正在运行的 ROS/RViz/pedsim 进程。

```bash
catkin build path_searching plan_manage --no-deps
catkin build path_searching plan_manage --no-deps --catkin-make-args tests
# ROS_MASTER_URI 指向独立测试 master：
catkin test path_searching plan_manage
```

控制器针对性测试覆盖：连续优化相对初始提议降低代价、完整状态/控制序列重演、
固定步态与转角界限、稳定权重、全无效输入、热启动移位、可复现采样、加权均值
落脚碰撞与非凸走廊间隙拒绝、当前周期可行回退，以及默认预算的冷启动直角转弯。
原有时间采样、未来横穿、执行延迟、最终目标终止与局部目标完整后缀检查均保留。

完整包测试还覆盖真实管理器的观测事务、失效 STOP、冻结状态/静止里程计、
执行前时间碰撞拒绝、路径恢复、目标切换与到达心跳，以及行人编辑器。
最终编译通过；两个包的完整测试均为零错误、零失败，控制器常规用例 21 项通过。
默认跳过的性能基准另外显式运行并通过。之后仅将可选基准的步长与权重对齐到
launch 默认值，重新编译并单独运行该基准，未更改运行算法。

轻量 launch 的 planner 3 / 4 及 Gazebo 默认入口参数解析通过，核对了两种控制器
各自的采样预算和转角配置。三个录制脚本通过 Python 语法检查（两个 `.sh` 文件
实际使用 Python shebang）。硬件 launch 的完整参数解析因环境缺少
`realsense2_camera` 未完成；本次未运行实机或 Gazebo 导航。

## 实际轻量仿真

通过临时 launch 使用实际轻量仿真流程，省略 RViz 窗口，关闭场景记忆以保留用户
上次配置。订阅实际诊断、里程计、轨迹和 Marker 消息；每轮清除测试目标节点私有
参数，避免上轮反向路线参数污染下轮。以下均为最终算法的 256×2、0.35 rad 参数。

| 场景 | 结果 | 有效规划 / 执行前时间复查 |
|---|---|---:|
| `mixed_turn_upper`，默认行人场景 | 到达 `(4.968, 4.722)`，目标 `(4.890, 4.688)` | 36 / 36 |
| `mixed_stress`，默认行人场景 | 到达 `(4.853, -4.459)`，目标 `(4.890, -4.412)` | 36 / 36 |
| 上方横向路线反向，临时未来横穿行人 | 到达 `(-4.145, 4.622)`，目标 `(-4.181, 4.637)` | 27 / 27 |

前两轮显式设置 sigma=.35，与最终默认值相同。未来横穿轮直接使用最终默认 launch；
其临时 YAML 仅把行人起点设为 `(0,3.5)`、速度 `(0,0.4) m/s`，尺寸保持
`(0.5,0.5,1.7) m`、trigger 周期 10 s，不修改仓库场景或用户记忆。
该轮记录 639 次动态拒绝查询，仍有可行替代轨迹，27 帧均通过执行前复查并推进。
拒绝计数包含采样/加权/重演检查，不是独立轨迹数或碰撞概率。
完整 10 步的时间路径保持 40 个点、末点约 +2.80 s，实际最终目标终止时路径缩短。

本次未人工检查完整 RViz/Ogre 画面；保留原有采样与选中轨迹显示、时间配对轮廓，
管理器测试核对预测位移、未来时间戳、冲突 STOP 和空帧清除。

## 计算开销

可选基准命令：

```bash
rosrun path_searching test_static_mpc \
  --gtest_filter=TimedMpcRuntime.DISABLED_BenchmarkSameMppiWork \
  --gtest_also_run_disabled_tests
```

10 步、256×2、sigma=.35、固定步长 .4 m，步宽零，代价权重与 launch 相同。
使用同一初始状态、宽走廊、目标与种子，交替启用/清除一个远离路径的移动凸包，
每次清除热启动并重设种子以保持采样一致。预热 5 轮后每种模式各测 100 次。

| 模式 | 中位耗时 | P95 |
|---|---:|---:|
| MPPI，无时间凸包 | 1.9952 ms | 2.1056 ms |
| MPPI，匀速凸包 SAT | 2.0459 ms | 2.1267 ms |

本机基准中时间检查的中位增量约 0.0508 ms（2.5%）。不包括地图更新、FIRI、
观测几何绑定、管理器执行前复查和 ROS 输出；这不是硬实时上界。
实际轻量运行的 MPPI 调用中位/P95 为：转弯路线 2.072/2.584 ms，
mixed_stress 2.284/2.560 ms，未来横穿 2.121/2.564 ms。
这些数值不代表完整规划事务时延；运行时序与可行率也不保证跨轮完全相同。
历史 beam 基准另见 [原记录](LFPC_TIMED_COLLISION_VALIDATION.md)，不能将不同
算法/预算的测量当作严格配对性能比较。

## 诊断与复现实验

原启动方式直接使用 MPPI：

```bash
roslaunch plan_manage sim_kin_replan.launch \
  planner:=3 use_pedestrians:=true pedestrian_scenario:=dwcg_crossing
```

RViz 的采样轨迹显示最后一轮实际采样，选中轨迹与时间同步轮廓沿用原话题。
新增 `/mpc/optimization_evidence`，可用 `rostopic echo` 查看迭代成本、采样可行数、
有效样本量 ESS、加权拒绝数和最终重演状态。索引定义随消息 layout 发布，也记录于
[MPPI 契约](../.trellis/spec/planning-runtime/lfpc-mppi.md)。
最低已验证代价曲线因保留候选而非增；不能将其视为局部最优证明。
该话题发布早于执行授权，最后是否推进仍看 STOP、时间复查与事务诊断。

## 适用边界

MPPI 仍可能漏掉窄通道内的可行序列；本次场景到达不代表任意路线都能通过。
固定步态不增加等待或减速动作；当前帧 FIRI 不释放未来可能空出的空间。
行人用匀速刚性平移凸包，检查仅覆盖离散质心八边形包络，未证明采样间连续安全、
完整人杖外形、行人转向/加速度或真实物理制动。
轻量仿真仍按 FSM 周期整步推进，预测时间不等于真实连续执行时钟。
