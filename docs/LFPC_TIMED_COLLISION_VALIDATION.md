# LFPC 时间同步凸包检查：验证记录

2026-10-26，分支 `mpc-lfpc-prototype`。该记录对应新增的匀速预测／SAT 检查，
不代表完整人杖连续运动或真实执行速度同步验证。

## 实现与运行

原命令默认启用：

```bash
roslaunch plan_manage sim_kin_replan.launch \
  planner:=3 use_pedestrians:=true pedestrian_scenario:=dwcg_crossing
```

RViz 的 `MPC_TimedCollision` 显示同时刻的机器人包络与行人凸包。颜色由青到紫，
文字为未来秒数；STOP 的红色 `Rejected` 表示一个被拒绝的样本。
`/mpc/timed_best_path` 的每个姿态头含未来绝对时间戳。默认机器人包络是覆盖
半径 0.25 m 圆盘的外切八边形；行人使用原有社会凸包，按观测速度刚性平移。

关闭新增检查做消融：追加 `mpc_timed_collision_enable:=false`。
改变包络：追加 `mpc_timed_robot_radius:=0.30`（有限正值，单位 m）。
这两个参数在节点初始化时读取；运行中仅修改 ROS 参数不会更新控制器。

## 自动检查

使用独立 ROS master，避免测试参数或时钟影响用户节点。执行：

```bash
catkin build path_searching plan_manage --no-deps
# 在独立 ROS master 环境下：
catkin test path_searching plan_manage
```

两个包的完整测试通过，零失败。性能基准默认不随常规测试执行。
新增用例覆盖接触／包含／旋转分离、非法输入、匀速横穿、观测年龄、跨步真实采样时间、
多步未来冲突、关闭检查恢复基线、执行时间原点复查、STOP 冻结模型和可视化清除。
管理器测试还核对了预测凸包位移与轨迹 PoseStamped 的未来时间。

## 计算开销

显式运行可选基准：

```bash
rosrun path_searching test_static_mpc \
  --gtest_filter=TimedMpcRuntime.DISABLED_BenchmarkSameBeamWork \
  --gtest_also_run_disabled_tests
```

10 步、每个首步 beam 宽度 8；相同地图、起点、目标和搜索工作量，交替执行关闭／
启用模式。启用模式放置一个不改变可行分支的移动凸包；预热 5 轮后各测 100 次。

| 模式 | 搜索中位耗时 | 搜索 P95 |
| --- | ---: | ---: |
| 无时间凸包检查 | 0.6855 ms | 0.7171 ms |
| 匀速凸包 SAT | 0.7029 ms | 0.7568 ms |

中位增量约 0.0174 ms（约 2.5%）。这是本机合成搜索基准，**不包括地图、FIRI、
观测几何绑定、管理器执行前复查和 ROS 可视化成本**，也不是硬实时上界。
缓存凸包投影只在绑定时生成，每个轨迹点最多检查双方凸包边数之和的分离轴；
执行前只复查根及选中序列，不重跑 beam。

## 实际启动验证

使用独立 master 和完整轻量仿真启动流程；未启动 RViz 窗口，通过实际 MarkerArray、
Path、诊断和 STOP 话题检查输出。测试进程关闭后清理，未重启用户原有节点，
关闭场景记忆以避免覆盖用户的上次配置。

- 原 `dwcg_crossing` 配置、已知可通行的上方横向路线：收到 28 帧有效带时间轨迹和
  28 次执行前复查，正常到达目标。完整 10 步轨迹为 40 个点、0.07–2.80 s，
  与当前浮点截断后的实际积分点数一致。
- 为验证未来横穿，将**临时测试场景**起点设为 `(0,3.5)`、速度 `(0,0.4) m/s`，
  身体尺寸保持 `(0.5,0.5,1.7) m`；路线从右侧上方返回左侧上方。
  观测到 34 帧时间检查，其中 30 帧有效轨迹／执行前复查，1151 次动态拒绝，
  3 帧“当前空间走廊可行但动态检查拒绝”的 STOP，以及对应 3 组红色冲突轮廓。
  行人通过后恢复前进并到达目标。动态拒绝数是搜索／复查中的拒绝查询数，
  不是独立轨迹数或碰撞概率。该运行的单次搜索耗时约 0.032–0.977 ms。
- 本次未人工检查完整 RViz/Ogre 画面；自动管理器测试核对了轮廓坐标、标签、
  时间戳和空帧清除，默认 RViz 配置已加入对应显示。

## 研究结论边界

当前帧空间走廊与新增时间检查同时生效；不释放未来可能空出的空间，不增加等待或
速度动作。检查只覆盖离散 LFPC 质心包络，不证明采样间连续无碰撞，也不预测行人
加速度、转向或往返终点行为。轻量仿真依旧整步跳变，模型时间与 FSM 的实际步频
不能视为连续执行同步。若开展完整时空安全实验，需要另行对齐执行时钟与轨迹跟踪。
