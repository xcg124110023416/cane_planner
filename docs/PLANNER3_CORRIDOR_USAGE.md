# Planner 3 走廊与人杖形状使用说明

2026-10-28 更新。当前凸包、预测检查及停车规则的区别见 [行为说明](PLANNER3_BEHAVIOR_NOTES.md)。原启动方式即可启用完整人杖包络、当前帧 DWCG/FIRI、时间同步行人检查与周期全局 A* 刷新：

```bash
roslaunch plan_manage sim_kin_replan.launch \
  planner:=3 use_pedestrians:=true pedestrian_scenario:=dwcg_crossing
```

在 RViz 设置起点和终点。已经运行的节点需要重新启动才会读取新参数；编译不会更新旧进程。行人源仍限制为零或一个行人。

## 看哪些图形

- `MPC_ActiveCorridor`：蓝色填充，实际用于当前规划的空间走廊，同时排除静态障碍和当前行人组合凸包。它不排除整段未来预测凸包，也不表示行人以后不会进入；未来安全性另看时间同步检查。
- `MPC_CorridorPreview`：浅色轮廓，远处预览，标注 `Preview only`。预览被阻挡会显示红色原因；它不触发当前停车，不替换路线。
- `MPC_HumanCane`：黄色为实际位置的人杖外形，无行人时也显示。轻量执行期间按真实 LFPC 姿态更新；其他执行模式保留青色预测外形。
- `MPC_TimedCollision`：人体/手杖与行人在相同时刻的匹配轮廓；红色为一次被拒绝的位置。轻量执行期间显示当前复检过的首步剩余部分，时间戳和行人外推随检查更新；完整 MPPI 预测仍见 `/mpc/best_traj`。
- 行人红色轮廓表示身体，紫色表示原始社会三角形，橙色表示真正用于避障的组合凸包；另有社会力箭头和 220° 视野线。

显示使用规划和碰撞检查中的几何；显示开关不会关闭碰撞检查。无效/过期观测清理预览，目标切换清理旧结果。预览有时间戳和短寿命，避免把过期远处图形保留在画面中。

## 调整走廊范围

```bash
roslaunch plan_manage sim_kin_replan.launch \
  planner:=3 use_pedestrians:=true pedestrian_scenario:=dwcg_crossing \
  convex_corridor_planning_length:=8.0 \
  convex_corridor_preview_length:=20.0 \
  convex_corridor_local_radius:=3.0
```

| 启动参数 | 默认值 | 含义 |
| --- | --- | --- |
| `convex_corridor_planning_length` | 8 m | 从实际位置沿参考路径取多长，必须大于 0 |
| `convex_corridor_preview_length` | 20 m | 预览多长；0 为剩余整条路线 |
| `convex_corridor_preview_enabled` | true | 是否计算和显示远处预览 |
| `convex_corridor_preview_period` | 0.2 s | 预览调度周期，支持 0.1–5 s |
| `convex_corridor_local_radius` | 3 m | 每块区域相对种子位置的扩张边界 |
| `convex_corridor_adaptive_sampling` | true | 根据当前区域的连续覆盖范围选择下一生成位置 |
| `convex_corridor_max_segment_length` | 1 m | 自适应模式的前向保护长度上限；旧式逐边生成的最大分段长度 |

两个长度独立。只希望看远一些，调预览长度；希望更远的路段也参与当前规划，调规划长度。规划长度和非零预览长度最大支持 80 m，地图仍受既有裁剪域/分辨率/栅格预算限制。整条路线超出地图或计算预算时，预览可能无法完成。

自适应生成时，每块区域先保护前方一小段原始质心折线，再根据该区域实际覆盖范围选择下一位置。只有第一块区域额外保护实际当前朝向的人杖凸包，后续不再叠加预测姿态或按人杖尺寸收缩走廊。保护长度默认最多 1 m，同时不超过区域半径的一半；它不是每块走廊的固定长度。只保护当前点可能在侧面障碍附近逐渐失去前进空间，这是本次办公室场景 `NO_PROGRESS` 的原因。

预览后台任务仅接收地图、参考路径及配置副本，独立 FIRI 预算最多 0.1 s；与活动走廊一样排除当前行人，非空行人帧标注 `current frame`。异步结果发布前会重新检查是否与当前行人相交，相交则清除旧预览。它不重算社会力、不恢复 A*、不读写控制器。A*、走廊和图中行人轮廓均按原始观测速度补偿到各自生成时刻；未来轮廓仍仅用于时间同步检查。地图副本获取仍有开销，不能将后台计算理解为零 CPU 成本。启用行人时，预览仍受原观测新鲜度约束，默认 0.5 s 的观测有效期保持不变。

## 调整人杖尺寸

| 启动参数 | 默认值 | 含义 |
| --- | --- | --- |
| `human_cane_body_radius` | 0.25 m | 人体包络半径 |
| `human_cane_cane_length` | 0.65 m | 从人体中心到前方小圆中心的水平距离 |
| `human_cane_front_radius` | 0.12 m | 手杖前端包络半径 |
| `human_cane_margin` | 0.03 m | 两个圆额外增加的安全余量 |
| `human_cane_enabled` | true | 完整人杖模型；false 供旧中心点/圆包络对照实验 |

例如将前伸距离改为 0.8 m，添加 `human_cane_cane_length:=0.8`。这些默认值来自项目已有仿真配置，实际人和设备需要标定。距离为平面投影，不等于手杖杆件的三维总长度。

第一版将人和杖看作刚性整体，方向采用 LFPC 预测的躯干朝向，不模拟手杖独立摆动。两个圆由外接多边形覆盖后取凸包。地图原有膨胀仍保留，因此窄通道可能比旧中心点检查更难通过，不能为了通过测试缩小真实身体尺寸。

## 调整行人形状

`pedestrian_social_radius` 默认 0.4 m，控制论文方向性关键点；`pedestrian_body_margin` 默认 0.03 m，控制身体矩形的独立余量。最终避障凸包同时包含身体和社会三角形，反向力也不会漏掉身体。

零合力且正在走动时，第三点沿速度朝向。静止时目前没有独立朝向输入，使用有余量的身体矩形；不把噪声速度当成可靠朝向。社会力仍为原先的简化斥力，多人及完整 SFM 没有在本次扩展。

## 周期全局 A* 与距离场

默认每 0.2 s 调度后台搜索，从请求时的实际当前位置到最终目标重新搜索，使用选定静态地图副本和同一观测的当前行人凸包。搜索整张地图，不限制在旧路径附近，不保留旧后缀，也不等待 MPPI 失败。行人凸包按原始观测速度补偿到搜索开始时刻；未来时刻的碰撞仍由 MPPI 时间同步检查负责。后台只处理不可变副本，不持有规划器或行人观测锁，搜索耗时不会直接阻塞局部执行。

原启动命令即可启用；例如请求每 0.1 s 刷新：

```bash
roslaunch plan_manage sim_kin_replan.launch planner:=3 use_pedestrians:=true \
  pedestrian_scenario:=dwcg_crossing global_replan_period:=0.1
```

`global_replan_period` 对应私有参数 `manager/global_replan_period`，支持 0.1–5 s。调度保持原定时间相位，小延迟不会累积为下一周期的额外等待；最多一个后台任务，忙时跳过，不补跑积压。轻量仿真只在落脚步边界接入候选，0.2 s 是搜索调度周期，不保证 `/astar/path` 达到 5 Hz；当前绕行实测平均发布间隔约 0.31 s。每次新目标使旧任务结果失效；刷新不重置 LFPC 步态或实际位置。

搜索质心参考折线，不检查未来人杖平移包络和转角姿态。当前人杖包络由走廊生成约束，与行人的未来碰撞由后续时间同步检查约束。每次搜索复制一次选定静态栅格，构建离障碍距离场；占用前缀和用于跳过完全空白的包围盒，仍对含障碍的区域执行质心线段与完整格子的分离检查。行人不写入持久地图，缓存也不跨搜索复用。仍保留额外一格路由余量。

候选结果先检查原始时效与目标版本，再连接到接收时的实际位置，重建活动 FIRI，以新路线产生转向提议并运行完整 MPPI。空间搜索时的行人帧仅用于引导；执行授权始终使用当前事务中的有效观测。全部通过原观测时效、选中序列重演和执行时间复查后，才提交到 `/astar/path`。候选失败不替换原路线；A* 搜索失败时，原路线也必须通过当前周期全部检查才可继续执行。其余情况保持冻结 LFPC 的 STOP 和静止里程计。

单次搜索预算最多 200 ms；启用行人时还不能超过原观测剩余有效期的一半。周期 A* 是空间搜索，FIRI 根据当前行人生成动态空间走廊；两者都不具备沿路径的时间维度。当前路径被行人阻挡而新参考尚未通过验证时，停止本次规划并清除有效走廊显示，不能退回纯静态走廊。新障碍可能在两次刷新之间被发现，期间仍可能短暂停止。当前地图仍按原配置选择，本地 SDF 未观测区域的乐观自由语义不变。

远处预览默认也每 0.2 s 调度，时间相位及本周期的调度判断时间与全局搜索对齐，避免可变计算耗时让预览任务在下一次换路前来不及发布。预览周期仍可独立使用 `convex_corridor_preview_period` 调整，支持 0.1–5 s；旧路线版本、过期观测或无效结果仍会被清除，负载高时不保证每次预览都能显示。

RViz 的 `/astar/path` 显示已经提交的整条新路线。`/mpc/convex_corridor_debug` 中 `route_scope=FULL_GLOBAL period=0.2 global_replan=SUCCESS` 表示全局刷新已提交。`SEARCHING` 表示后台任务未完成，`READY` 仅是待验证候选；`NO_PATH`、`TIMEOUT`、`REBUILD_FAILED`、`MPPI_REJECTED`、`EXPIRED`、`EXECUTION_REJECTED` 区分失败阶段。`NOT_NEEDED` 表示本周期未尝试刷新。控制台的成功日志有 0.5 s 节流，不能用打印行数测刷新率；应测 `/astar/path` 的实际发布间隔。原诊断数组 33 个字段位置保留；14 和 22–28 描述已完成的后台搜索（其中 24 为请求时地图快照耗时），不是当前回调内的阻塞搜索时间；15 记录候选 FIRI，16 记录单次 MPPI，18/19 用于查看实际回调耗时。

最新测试和办公场景结果见 [全局刷新验证记录](PLANNER3_GLOBAL_REFRESH_VALIDATION.md)。以下保留历史加速记录。

以下为 2026-10-27 距离场加速时的历史基线，使用旧当前帧恢复逻辑：原办公室地图、起点 `(-6.393,4.190)`、终点 `(3.633,-4.828)`、已记忆的 2 m/s、2 s 后消失行人场景，无界面复现结果：初次 A* 从约 208 ms 降至 28 ms；动态恢复从 7 次各约 200 ms 超时，变为 15 次各约 38–43 ms 搜索完成（含最终边复检）。当时的加速没有建立成功绕行。

这 15 次旧版恢复都在随后走廊重建时被拒绝，调试字段为 `recovery=REBUILD_FAILED`。旧 A* 只检查质心线段绕开行人，可能贴凸包太近，无法容纳完整人杖包络。当时据此扩展了未来整个人杖的空间硬约束；本次按用户明确的建模用途撤销该扩展，只保护当前凸包。旧版搜索完成仍不能解释为可执行绕行。

上述为同一场景参数的两次闭环运行，地图/行人采样时序与路线可能不同，并非冻结同一搜索输入的微基准。单个 A* 回归另以实际调用计数验证：159 次软代价查询引起的额外地图提取从 159 次减为 1 次。

## 检查范围与验证

只有走廊生成时的实际当前人杖凸包须落在一块区域中。预测轨迹检查质心在走廊内，不再要求未来整包络包含或进行整包络的静态碰撞判断。MPPI 搜索、加权结果重演和执行前时间复查使用相同位置、朝向、时间。LFPC 在步边界改变朝向，与行人的时间同步检查会以不超过 5° 间隔检查中间转角，并在执行前复查中保留这些姿态；它们共享该步边界的模型时间。

轻量仿真现以 20 ms 定时器按实际经过时间推进 LFPC，并在每次推进前重查当前观测、质心与落脚点的静态可通行性、质心在已接收走廊内及剩余步态的行人碰撞；额外加入不超过 20 ms 的模型采样。有效步时保留 `int(t_sup/delta_t)*delta_t` 规则，例如本机 0.35/0.07 实际为 0.28 s。转向仍只在步边界切换，单次延迟最多推进 40 ms，不补跳整步。STOP 冻结实际阶段，复检通过后才续走；它不是步内重新优化转向或物理制动。

执行期间重算的参考走廊用于下一步诊断；若它报告 `REFERENCE_OCCUPIED`，并不直接撤销已接收的当前支撑相。当前动作仍由执行器按最新地图与行人检查，不通过才 STOP。`/mpc/stop_reason` 与执行诊断表示实际停车状态。

`/mpc/execution_diagnostics` 的 8 个字段依次为版本、ROS 时刻、实际阶段、有效步时、实际推进量、是否停车、当前观测代数、复检耗时。规划诊断字段 21 在排入首步时保持 1，表示没有立即整步积分；不能据此判断是否正在运动。

这些仍是离散姿态检查，不构成采样之间连续扫掠安全、真实手杖姿态或物理制动证明。Gazebo、实机及其他 planner 的执行适配保持原样。

验证用例覆盖身体与完整圆盘覆盖、反向力/零力、朝向影响、手杖前端单独碰撞、朝向 SAT 缓存、执行时延、原始折线覆盖和转角、500 边路径生成预算、快照 v1/v2 兼容与 v3 几何参数回放，以及远处预览失败不改变当前计划。

此前包含未来整包络空间约束的版本，在本机相同 MPPI 预算（10 步、256 样本、2 轮，单个远处行人）测得：旧中心点/圆包络中位约 2.29 ms，完整人杖及中间转角检查约 14.64 ms，P95 约 14.91 ms。该数值不包含 FIRI、地图与 ROS 开销，不是整个规划周期或硬实时上界。可用以下命令重新测量：

```bash
rosrun path_searching test_static_mpc \
  --gtest_filter=FootprintMpcRuntime.DISABLED_BenchmarkSameBudget \
  --gtest_also_run_disabled_tests
```
