# Archived MPC Notes

These files are preserved for development history, but they are not the current
research roadmap for the RAL-oriented DRF-only MPPI work.

Use the current root-level documents instead:

- `MPC_LIGHTWEIGHT_ABLATION_NOTES.md`: current research direction, method scope,
  and next real-world demo priorities.
- `MPC_STAGE1_EXPERIMENT_TABLES.md`: current Stage 1 simulation tables and
  generated figure paths.

Archived files:

- `MPC_RAL_TODO.md`: earlier broad RAL TODO plan. It contains now-rejected
  directions such as making CPA/TTC a primary method component.
- `CLAUDE.md`: older MPC prototype note. A new root `CLAUDE.md` now points to
  the active DRF-only roadmap.
- `ARCHITECTURE.md`: early global/local planning architecture note; the file is
  also partially garbled.
- `math.md`: incomplete scratch math note.
